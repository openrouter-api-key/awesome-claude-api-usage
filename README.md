# Awesome Claude API usage

*Unofficial community list for Claude API usage. Not affiliated with Anthropic. All trademarks belong to their owners.*

A curated list for claude api usage in both senses: getting started with the Claude API through the Console, and tracking cost and usage once you are running. Only pages that the top-ranking sources for the query link to are included, which keeps the list honest and short. The claude.ai usage settings page is listed under Related with a warning, because it is the page most people confuse with API reporting.

## Official resources

- [Claude Console](https://platform.claude.com/) - Sign in with Google, email or SSO; the home of API keys and usage reports.
- [Developer docs](https://platform.claude.com/docs) - Main documentation site.
- [API reference](https://platform.claude.com/docs/en/api/overview) - Endpoint and field reference, including the usage object on responses.
- [Quickstart](https://platform.claude.com/docs/en/get-started) - First request walkthrough.
- [Cookbooks](https://platform.claude.com/cookbook/) - Worked notebooks and recipes.
- [Docs intro (docs.claude.com)](https://docs.claude.com/en/docs/intro) - The docs entry point linked from the support center.
- [Pricing](https://claude.com/pricing#api) - Current per-model API prices.
- [Claude Platform overview](https://claude.com/platform/api) - Product page for the API.
- [Download the Console app](https://platform.claude.com/download) - Desktop download linked from the Console footer.
